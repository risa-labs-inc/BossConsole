# Scaffold Gradle wrapper

Source: https://github.com/gradle/gradle/blob/v8.7.0/gradle/wrapper/gradle-wrapper.jar
SHA-256: cb0da6751c2b753a16ac168bb354870ebb1e162e9083f116729cec9c781156b8

The generated standalone plugin uses Gradle 8.7 with Kotlin 2.0.21, independently
of the host build toolchain. Its distribution checksum is pinned in
PluginScaffolder. Update the wrapper, distribution checksum and scaffold build
validation together when upgrading this template.
