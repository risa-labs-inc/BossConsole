# BOSS v9.5.30

**Release Date:** 2026-09-28

On macOS, the terminal's sharing, call and MCP controls move into the native window toolbar,
grouped beside Search, Tools and Toolbox. A live call's controls now follow the window rather than
the selected tab, and the bottom status bar is hidden by default on desktop (#1754).

## Highlights

- **Terminal controls in the macOS toolbar** (#1754). The terminal plugin's sharing, call and MCP
  controls appear in the native title bar as one grouped control with SF Symbols, and each
  segment shows whether its service is on. Search, Tools and Toolbox share a second group
- **Call controls follow the window** (#1754). While a call is live, its controls stay in the
  bottom-right corner of the window whichever tab is selected, terminal or browser
- **The bottom status bar is off by default on desktop** (#1754). A window now opens as its content
  and vertical tab bar, and this applies to existing installs too. The View menu brings the
  status bar back

## Features

- **macOS**: terminal sharing, call and MCP controls are hosted in the native title bar through the
  new `TerminalTitleBarBridge` in plugin API 1.0.95. Hosts without support keep the terminal's
  floating controls (#1754)
- **macOS**: toolbar items are grouped, with one shared glass background for terminal controls and
  one for Search, Tools and Toolbox (#1754)
- **terminal**: live call controls show across all tabs in a window, not only on the terminal tab
  (#1754)

## Improvements

- **window**: the bottom status bar is hidden by default on desktop, alongside the top bar and both
  icon strips (#1754)
- **terminal**: the host's claim on each window's terminal controls is released when the window
  closes, and overlapping owners fall back to the previous one when the newest goes away (#1754)

## Dependencies

- Plugin API bumped to 1.0.95 (#1754)
