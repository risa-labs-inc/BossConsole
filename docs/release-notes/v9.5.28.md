# BOSS v9.5.28

**Release Date:** 2026-09-27

A short follow-up to v9.5.27's native macOS toolbar. MCP agents can now check for, download and
install BOSS updates through governed tools (#1743). The packaged macOS app now gets the native
toolbar glass (#1742), dragging the sidebar narrow collapses it (#1741), and the New Tab dialog
focuses its input again (#1745).

## Highlights

- **Application updates over MCP** (#1743). Four host tools expose the existing updater:
  `app_update_status`, `app_update_check`, `app_update_download` and `app_update_install`.
  Check, download and install return `accepted` straight away and run in the background, so an
  agent polls `app_update_status` for progress and errors. Only one update operation runs at a
  time. Install takes the exact staged `version`, and no tool accepts a URL or installer path.
  Installing uses the UI updater's own signature, checksum and permission checks, and it may
  quit and relaunch BOSS, which disconnects MCP. Status is read-only. The other three are
  rated HIGH risk and ask for approval by default. See `docs/app-update-mcp.md`
- **Native toolbar glass in the packaged macOS app** (#1742). jpackage ships a launcher built
  against an older macOS SDK, and AppKit reads that SDK version to decide whether to use the
  macOS 26 toolbar styling. A new `prepareMacOSAppearance` step raises the launcher's SDK
  version to 26.0 after packaging and re-signs the bundle. The deployment target and launcher
  code are unchanged. The release workflow checks the result before publishing
- **The sidebar collapses when you drag it past its minimum width** (#1741), as it does in
  BossTerm. While dragging you see a narrow preview. Releasing below the minimum hides the
  sidebar and keeps the width the sidebar toggle brings back. Dragging a revealed sidebar wider
  expands it again

## Features

- **mcp**: add `app_update_status`, `app_update_check`, `app_update_download` and
  `app_update_install` tools for the application updater, with the three mutating tools in the
  mutating catalog and rated HIGH risk (#1743)

## Bug Fixes

- **macOS**: enable native toolbar glass in the packaged launcher by setting its SDK version
  to 26.0 and re-signing the bundle (#1742)
- **sidebar**: collapse when resized below the minimum width, keeping the width the toggle
  restores, and expand a revealed sidebar when it is dragged wider (#1741)
- **tabs**: the New Tab dialog focuses its URL or file input once its own dialog window has
  focus and its content is laid out, not while the opening window still has focus (#1745)

## Improvements

- **build**: `build.yml` and `release.yml` check that the macOS launcher's SDK version turns on
  the native toolbar styling. `scripts/test/test-prepare-macos-appearance.py` covers the
  script (#1742)
- **docs**: new `docs/app-update-mcp.md` on the update tools, how to poll them and what install
  can do to the running app (#1743)
