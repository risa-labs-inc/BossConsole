# BOSS v9.5.27

**Release Date:** 2026-09-26

On macOS, BOSS now uses a native title bar and toolbar, like BossTerm's: the focused browser
pane's back, forward, reload and address field sit in the window's own toolbar, and the sidebar
continues up behind it (#1736). Separately, the automatic "Last Session" entry is now hidden
from the Space pickers unless you turn it on, and session restore brings back each Space's own
identity (#1736).

## Highlights

- **Native macOS title bar with browser navigation** (#1736). The focused browser pane puts its
  navigation into a native AppKit toolbar: back, forward, reload/stop, bookmark, share and an
  editable address field with suggestions and a copy button. The window title follows the
  window's Space and project, and session controls match BossTerm's. A browser whose window hosts
  these controls hides its own in-tab toolbar. Hosts and plugins without support keep the in-tab
  toolbar as before
- **Integrated, hideable sidebar** (#1736). The main-window panel's background now runs up
  behind the native toolbar. When the collapsed rail is hidden, a 44 dp hover edge on the window
  side reveals the drawer, and it also works above a native Chromium view. Quick actions move into
  the title bar when it is available, so they stay reachable with the rail and top bar hidden
- **Last Session is opt-in in the Space list** (#1736). A new **Settings > Spaces > Session
  Restore > Enable Last Session Space** toggle is off by default, including for existing settings
  files. Startup still restores what you were running. It now reopens the Spaces themselves with
  their own ids, even when only one was running. An old recovery snapshot that has no original
  identity comes back as a normal "Recovered Space" instead of losing its tabs

## Features

- **macOS**: native title bar and toolbar with browser navigation, address editing, suggestions
  and a copy button, plus title and session actions scoped to the window (#1736)
- **browser**: new `BrowserTitleBarBridge` in the browser plugin API (1.0.94), which lets a
  browser plugin publish its navigation state to an optional host toolbar. Older hosts leave the
  bridge unclaimed and the browser keeps its in-tab toolbar (#1736)
- **sidebar**: hidden-rail hover edge, a main-window panel that extends behind the toolbar, and a
  background context menu on the pane strip (#1736)
- **spaces**: Session Restore setting to show or hide the Last Session entry, which Settings
  search also finds (#1736)

## Bug Fixes

- **macOS**: the address field keeps focus when the window moves between screens (#1736)
- **browser**: the host keeps its claim on the browser toolbar when the browser recomposes, so
  the in-tab toolbar no longer reappears (#1736)
- **spaces**: the identity-preserving session set is now refreshed along with the crash-recovery
  file, so a crash cannot restore an older set over newer edits, and a new window no longer takes
  the hidden recovery slot as its visible Space (#1736)
- **search**: filename navigation uses the results it found when a large project goes over the
  discovery budget, instead of failing. Malformed ignore rules still fail closed (#1736)

## Improvements

- **tabs**: tab icons use a sharper cached favicon for the same site when one is on disk. This
  needs no network request, and a pixel comparison makes sure it is the same icon (#1736)
- **tabs**: pane tab chips centre their icons and draw one shared background per row (#1736)
- **overlays**: heavyweight overlays share one overlay-window implementation (#1736)

## Dependencies

- **plugin-api**: `boss-plugin-api` 1.0.93 -> 1.0.94 (#1736)
