# BOSS v9.5.39

**Release Date:** 2026-10-05

New windows start in a simple default Space, Planet Berul, and the Space menus now lead with your
five most recent Spaces (#1828). First-run onboarding only asks about the default browser and can
be skipped, and the hidden sidebar reveals itself at the window edge.

## Highlights

- **Simpler default Spaces and recent Space menus** (#1828). A first window that restores
  nothing opens in the empty Planet Berul Space instead of an unassigned window. The Space menus
  list your five most recent Spaces first, with the rest under More and the shipped layouts under
  Templates; session recovery records stay out of them, and Spaces sharing a name are numbered so
  each stays selectable
- **Top of Mind from the title bar** (#1828). Clicking the Space selector in the title bar opens
  Top of Mind, with the downward arrow and native chevron styling restored
- **Lighter onboarding** (#1828). The first-run offer now only asks to make BOSS your default
  browser, never preselects or claims file types, and has a Skip button that works even while a
  claim is in progress. File defaults stay in Settings > Default Apps
- **Sidebar reveal at the window edge** (#1828). Moving the pointer to the window edge reveals a
  hidden sidebar, and the bottom status bar is shown by default again

## Bug Fixes

- **workspaces**: windows with no Space assigned are given the default Space after startup, even
  when session restore was refused; recovery Space identities are reused rather than duplicated,
  and Space persistence and the default-offer lifetime are fixed (#1828)
- **chrome**: the native macOS Space button finds its identifier correctly on click, and its text
  matches the native toolbar styling (#1828)
- **projects**: selecting a project no longer opens the CodeBase panel automatically (#1828)

## Improvements

- **chrome**: the bottom status bar is visible by default on desktop; the View menu still hides
  it (#1828)
