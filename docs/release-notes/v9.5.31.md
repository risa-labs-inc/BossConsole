# BOSS v9.5.31

**Release Date:** 2026-09-28

On macOS, BOSS adds Liquid Glass Light and Dark themes that let the desktop show through the main
window, in BossTerm's style (#1756). Tab dragging now needs a deliberate movement and previews
which side of a pane a split will land on (#1755).

## Highlights

- **Liquid Glass themes on macOS** (#1756). Two new Blueprint palettes, Liquid Glass Light and
  Liquid Glass Dark, put a native glass backdrop behind the main window, with the vertical sidebar
  and content sharing one surface. Glass coverage, style and tint are saved separately from the
  palette, and Reduce Transparency is respected. Windows and Linux keep opaque palettes
- **Wallpaper behind fullscreen glass** (#1756). In fullscreen, the glass window shows your desktop
  wallpaper instead of an empty Space, falling back to a theme colour when the wallpaper cannot be
  read
- **Deliberate tab dragging with directional split previews** (#1755). A tab only starts dragging
  after the pointer has clearly moved, the split overlay now also shows on the pane the tab came
  from, and left, right, top and bottom placements land where the preview said

## Features

- **macOS**: Liquid Glass Light and Dark themes with a native glass backdrop on the main window,
  following BossTerm's tint and background-opacity defaults (#1756)
- **macOS**: the vertical sidebar gets glass-aware washes, selection fills and hairline separators
  while the backdrop is active (#1756)
- **macOS**: the focused terminal tab's live title appears in the native toolbar right after the
  Space selector, and disappears on other tabs (#1756)
- **macOS**: exiting pane fullscreen is available from the native toolbar (#1756)

## Bug Fixes

- **browser**: the native toolbar address field stays available on the browser Home page (#1756)
- **sidebar**: the hidden-sidebar hover edge no longer reveals the sidebar in fullscreen (#1753)
- **sidebar**: dragging the sidebar below its minimum width collapses it exactly as in BossTerm
  (#1756)
- **tabs**: small pointer movements while clicking a tab no longer start a drag (#1755)
- **tabs**: dropping a tab onto its own pane shows the split overlay and splits in the direction
  previewed (#1755)

## Improvements

- **macOS**: glass tint is painted once across the title bar and content, with the sidebar's
  rounded cutout kept, so no area is double tinted (#1756)
