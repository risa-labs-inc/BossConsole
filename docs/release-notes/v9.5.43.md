# BOSS v9.5.43

**Release Date:** 2026-10-09

On macOS, BOSS now keeps running in the Dock after its last window closes and can install
automatic updates while idle (#1844). This release also reworks the collapsed sidebar's hover
reveal (#1853), moves the browser engine to JxBrowser 9.5.3 (#1849), and lets a headless BOSS adopt
a sign-in handed to it through a private file (#1833).

## Highlights

- **BOSS stays in the Dock on macOS** (#1844). Closing the last main window no longer quits; a Dock
  click or File > New Window opens a window again, and Quit still ends the app. Automatic updates
  install while no windows are open and relaunch without a window, and Quit finishes reliably even
  when plugin or Compose teardown fails
- **Smoother collapsed sidebar** (#1853). The hover reveal now overlays the content as a native
  child of its window, with synchronized, faster open and close transitions that stay anchored
  while the window is resized
- **Headless session import** (#1833). `BOSS_SESSION_IMPORT` names a strictly checked, owner-only
  file whose refresh token a headless BOSS adopts as its session, consumed on first use
- **A calmer sign-in screen** (#1857). The brand panel pauses its animations after 8 seconds without
  activity or when the window loses focus, instead of holding around 45% CPU on macOS

## Features

- **auth**: import a session from a `0600` file for headless servers and containers, with ownership,
  mode, symlink and write-stability checks; a refused file is left in place and the reason logged
  once (#1833)
- **app**: on macOS BOSS keeps running without windows, and automatic updates install when no main
  window remains, relaunching with `--no-window` (#1844)
- **boss-ai**: operators can set OpenRouter provider routing per model, validated by one shared
  allow-list in the table and the function (#1854)
- **boss-ai**: new `ai.optimist` permission for an organisation-scoped model (#1850)
- **fluck-web**: sign in at the Fluck web portal and open your Fluck web chat through single-use
  tickets (#1847), embedded in a full-viewport frame (#1852), launched on the chat's own splash
  (#1858) and restyled in the web chat's visual language (#1859)
- **fluck-web**: the portal is now also served at fluck.ai, with isolated origin configuration and
  working email sign-in (#1863)
- **fluck-vault**: per-install keys, proven rotation, operator-approved issuance and ISO 4217
  amounts (#1830), plus a sealed `secret` kind for API keys and connector tokens (#1832)
- **fluck-oauth**: per-install signed state, a `/refresh` route and grant binding (#1831), the GitHub
  OAuth App client id at `/client` (#1835) and Slack user-token OAuth (#1836)

## Bug Fixes

- **sidebar**: the collapsed hover reveal attaches to its native owner window, keeps its closing
  layout, saves resized widths and releases width when a hover interrupts a button close (#1853)
- **app**: native Quit races, pop-out window retries and idle update arming are fixed, and Quit
  completes after a failed Compose disposal (#1844)
- **app**: resource cleanup is isolated across dialogs, tabs and browser owners, so one failing
  teardown step no longer skips the rest (#1844)
- **wizard**: in-place cleanup during staged installs matches the refusal rules (#1648)

## Improvements

- **auth**: the sign-in brand panel goes idle when nobody is using it (#1857)
- **auth**: authentication callbacks are allowed for askoptimist.com (#1856)
- **auth**: renamed the exclusive lock-file helper and kept atomic writes for the session key (#1773)
- **tests**: the Windows inconclusive path in the user-data storage merge test is now observed and
  reported (#1791)

## Dependencies

- **browser**: JxBrowser 9.5.2 -> 9.5.3 (#1849)
