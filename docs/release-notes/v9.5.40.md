# BOSS v9.5.40

**Release Date:** 2026-10-06

A fresh macOS install no longer crashes on its first launch: BOSS now restarts itself once the
browser engine finishes downloading, instead of booting it in the running process (#1834). The
hidden sidebar also stays closed in fullscreen when the pointer touches the window edge.

## Highlights

- **No more first-launch crash on macOS** (#1834). On a fresh install the browser engine was
  downloaded and then started inside the same launch, which could crash BOSS about 15 seconds in.
  Packaged macOS builds now restart BOSS when the engine download completes, so the engine always
  starts the safe way. Only the setup window is open at that point, so nothing is lost
- **Links and files survive the restart** (#1834). `boss://` links, files and requests from a
  second launch that arrive before the main window opens are carried across the restart and
  replayed, treated as external requests so they still ask for confirmation where needed
- **Sidebar edge reveal is off in fullscreen again** (#1834). A fullscreen window no longer
  opens the hidden sidebar whenever the pointer reaches its left edge

## Bug Fixes

- **crash**: packaged macOS builds relaunch after the first-run engine download (and after
  update or engine-change downloads) rather than booting the engine with AppKit already
  running (#1834)
- **crash**: if the relaunch cannot start, BOSS withdraws the handoff, requeues pending requests
  and boots in process instead of exiting with nothing coming back; a translocated app bundle is
  not relaunched (#1834)
- **sidebar**: the native cursor tracker that reveals the hidden sidebar now respects fullscreen,
  restoring the behaviour from #1753 (#1834)

## Improvements

- **startup**: the setup window reads "Restarting BOSS to finish setting up ..." at 100% during
  the relaunch instead of falling back to "Connecting ..." at 0% (#1834)
- **startup**: the relaunched process forces the browser pre-warm, as the in-process path did
  for a fresh profile, and non-credential `BOSS_*` overrides are forwarded to it (#1834)
