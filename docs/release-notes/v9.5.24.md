# BOSS v9.5.24

**Release Date:** 2026-09-24

A large reviewed dev batch (#1680, 554 files) brings MCP secret references, plugin packs, a snippet
library and notification inbox, and a long run of security hardening across the CLI, deep links,
plugins, the database and the edge functions. The navigation map also gains a visible full-screen
button on every pane (#1606).

## Highlights

- **Secret references in MCP tool calls** (#822). A governed tool's arguments can carry
  `{{secret:<id>}}`, which the host resolves after the operator approves and before the handler
  runs. The value never enters the arguments, result, approval dialog, ledger or log. A
  secret-bearing call always asks: tool or provider ALLOW, session trust and YOLO mode never
  satisfy it. Resolution is all or nothing, and one bad reference refuses the whole call
- **A saved Always Allow no longer covers a destructive shell command** (#1613, #1650). A shell
  call the risk evaluator rates CRITICAL is asked again every time, with the prompt marked
  escalated, and on that prompt "Always, for this tool" can only deny. A saved DENY is never
  overridden
- **Plugin packs, snippets and a notification inbox for agents** (#838, #1500). `pack_plan`,
  `pack_apply` and `pack_status` (plus `boss pack plan|apply|status`) install the plugins a desk
  needs and the MCP rules that make their tools usable, inside the existing approval dialog. A
  host-owned snippet library and a durable operator notification inbox each get their own MCP tools
- **Canvas apps get the trackpad pinch** (#1567). On macOS a pinch used to zoom the whole page, so
  Excalidraw, Figma and similar apps had their UI scaled instead of their canvas. Each delta is now
  offered to the page as a cancelable Ctrl+wheel event, the way Chrome and Safari deliver it, and
  only a declined delta zooms the page

## Features

### MCP

- **Agents can ask BOSS how it is doing** (#1369): workspace health and the performance snapshot
  are reachable as an MCP tool, so an agent can check for a degraded host before opening more tabs
  or terminals. The status bar shows workspace health too (#1548)
- **Approval queue controls** (#1507), and the approval dialog now shows the tool's description and
  the policy that applied (#1462)
- **System path bounds on the workspace and terminal tools** (#1024)
- **Snippet and notification tools are paged and bounded** (#1660, #1644, #1666, #1670), and each
  notification is stamped with its source at the service boundary (#1619)

### Spaces and navigation

- **Full-screen mark on every navigation map pane** (#1606). Double-click was the only way in and
  only a hover tooltip said so. Each pane big enough now shows a small maximise button at rest; one
  click shows that pane full screen. The pane's right-click menu gains "Full Screen (double-click)"
- **Persona layout presets** for data science, research and devops (#1143)

### Browser

- **Export bookmarks** (#1600). Help > Export Bookmarks... writes every collection to a Netscape
  bookmark file that any browser can import, one folder per collection

### Onboarding

- **Improved first-run wizard and a welcome overlay** (#623): a four-step agent connection wizard,
  benefit-driven plugin descriptions, a first-session banner and a Getting Started entry in Settings

## Bug Fixes

### Security

- **CLI**: an `&` in `boss <anything>` can no longer run a second command (#1594), a quote in any
  `boss.bat` argument can no longer inject PowerShell (#1059, #1658), hidden formatting characters
  are rejected, an over-long path is treated as restricted (#1653), and PowerShell's typographic
  quotes are quoted in shell strings (#1419)
- **Deep links**: `boss://plugin` action links from outside BOSS are held for confirmation, and
  retained until a window can ask (#869, #1555). On Windows, `boss://file`, `folder` and
  `workspace` links can no longer make the OS send NTLM credentials to a remote SMB host (#1129).
  The auth ceremony segment is parsed by structure, not substring (#1348), and URLs that break the
  single-instance channel's line framing are refused (#1441)
- **Sign-in**: Supabase session tokens persist through an encrypted Settings backend (#918), and
  `isAdmin` and permissions are read from the access token's claims instead of `user_metadata`
  (#1113, #1559). The passkey maintenance endpoint requires the service key and rate-limits on the
  gateway hop (#1335); plugin and passkey identity are bound to trusted server values (#1496)
- **Plugins**: api-claiming jars are verified before `ApiClassLoader` installs them (#908), an
  update's downloaded jar identity is vetted before the swap (#947), staged downloads are verified
  before replacing installed jars (#1111), path-shaped dev plugin ids are refused (#1486), bundled
  trust markers and rollback snapshots publish atomically (#1109, #1132), and each class file is
  capped before its class loader reads it (#1625)
- **Kernel and IPC**: the kernel IPC transport is bounded against abuse (#1379), five more service
  bridges require a verified caller identity (#1339), the revoke-if-current token is compared in
  constant time (#1040), and the `watchState` subscribe gap is closed (#1510)
- **Files and editor**: editor-service saves are confined to the user's home, resolve symlinks and
  save atomically (#891). On Windows a file opens through Explorer instead of a cmd shell (#1371,
  #1561)
- **MCP**: workspace ids can no longer select files outside the workspace directory (#880, #958,
  #964, #1076, #1643), the startup-command refusal is shared across `open_workspace` modes (#957),
  and the v9.5.21 workspace tool family is classified in the risk evaluator (#893). Credential
  masking covers URI authorities and encrypted PEM bodies, and no longer masks a container
  `uid:gid` (#1656)
- **Browser**: `javascript:` and unknown-scheme URLs are refused before execution or logging (#931),
  as are malformed and credential-bearing authorities (#1597). The stale-Chromium sweep is scoped
  to this instance (#1461)
- **Git**: a remote branch that strips to a flag such as `-f` can no longer force-discard
  uncommitted work on checkout (#930, #950). Clone URLs are validated with `--` before git's argv
  (#1145), control characters including NEL and U+2028 are refused (#1611, #1662), and the clone
  dialog no longer logs the raw clone URL (#1609)
- **Logging**: Supabase's current `sb_publishable_` and `sb_secret_` key shapes are masked (#897),
  and a URL's userinfo is kept out of free-text log lines, protocol-relative URLs included (#956,
  #1663)
- **Settings and state**: keymap, zoom and Space settings persist owner-only (#937), settings
  writes are serialized (#1032), the remaining state managers write atomically (#1022), and temp
  bytes are forced to disk before the atomic move (#1330)
- **Server**: the placeholder server binds to loopback instead of all interfaces (#1038)

### Database and edge functions

- **Role-reading RPCs no longer answer for users the caller cannot see** (#1074); the token hook's
  role helper and `get_user_api_key_count` are taken away from client roles (#994, #1638); and
  `search_path` is closed on the invoker and fixed-path definer functions (#993, #1504)
- **Plugin store**: catalogue inputs, popular tags, ratings pagination and remote-JAR range fetches
  are bounded (#1508, #1541, #1671, #949, #952), rater UUIDs are no longer returned, an unfinalized
  version never resolves as latest (#954), and API key audit fields are shaped at the persistence
  boundary with the rate limiter keyed on the gateway's forwarded hop (#1332, #1664, #1647, #1070)
- **Organisation**: script-driven posts are refused at the CSRF gate (#969), unverified domain
  claims are capped and expire (#971), and the session-optional plugin page render is rate-limited
  (#970)
- **BOSS AI**: exchange-ticket single-spend and the issuance cap hold under concurrent sessions
  (#1501)

### Git

- **Refresh loop, stale diffs on branch switch and a sticky commit error are fixed** (#1621), with
  clearer error handling in the diff provider (#1626)
- **Status parsing** reads porcelain v1 `-z`, so staged files, renames, copies and typechanges
  resolve correctly (#1564, #1554, #1175, #1173); refresh and clear are serialized (#878)
- **Create PR URLs percent-encode branch names** (#1512), and `runInTerminal` arguments are
  shell-quoted (#1485)

### Keyboard

- **Fast shortcut taps are no longer dropped** (#1568, #1571). A shortcut ran on the key release and
  a modifier coming up a few ms early cancelled it; it runs on press again
- **macOS shortcuts require exact primary modifiers** (#1529)

### Terminal

- **One-shot commands can exit**: stdin closes on demand (#940). Sessions spawn outside the service
  lock with bounded stdin writes (#939), and concurrent senders queue instead of spinning (#1527)

### Browser

- **An interrupted engine swap is recovered at startup** (#977), and the reinstall is atomic with
  rollback
- **Favicon decode moves off the JxBrowser callback thread** (#1494), dead popup captures release
  promptly with auto-open bursts capped (#1525), the field-detection script is injected once per
  document (#884), and resolved-host persistence is serialized (#1622)

### Spaces and windows

- **Space saves stay window-local and report honestly** (#741), `&&` in Windows project paths is
  preserved (#1522), and an id-less import gets a stable id instead of writing `.json` (#1435)
- **Closing a window retires its pending state** (#1523), outgoing tree tabs are disposed in
  `clearAllPanels` (#1344), closed-tab snapshots are sanitized (#1536), and shared runner window
  ownership is preserved (#1518)

### Dashboard

- **"Yesterday" means the previous calendar day**, not 24-48 hours ago (#1096); project-card dates
  use an explicit locale (#1044) and `app.build.date` is ISO and UTC (#1101, #1560). Project and
  stats persistence is atomic and merges the initial load (#1519)

### Kernel and plugins

- **Each child death is reported once and only the dead registration is evicted** (#1516, #1652),
  out-of-process plugin crash supervision is wired (#499), and the mastery orchestrator uses the
  kernel's live capability registry (#1153)
- **Mastery definitions are re-validated at load** (#1514), conditioned edges are refused until
  they can be evaluated (#1067), and guarded skips surface as `NodeSkipped` progress events (#1144)
- **A plugin that cannot be linked returns a Result instead of throwing** (#1131); the first-run
  wizard skips a plugin only when it is actually installed (#563, #1640); a background task handle
  is released even when the task finishes first (#1581)
- **The Downloads folder resolves one way** for the browser and both providers (#1552)

### Other

- **Updater installs only from the volume hdiutil reports** (#936), and release-notes emphasis needs
  word-boundary flanks (#1498)
- **Startup settings persist atomically** with a fenced async load (#1505); live SQLite databases
  are snapshotted consistently on import (#959)
- **Performance monitoring** bounds its per-tick thread scan (#1524) and keeps a failed panel action
  off the crash handler (#1097); network retry advances correctly (#1521); download progress
  updates one entry per tick (#1474)
- **Render recovery allowances are bounded per incident** (#899); superseded run scans are ignored
  (#1480); the installed CLI version keeps its pre-release suffix (#1530); the login screen cancels
  its scopes on disposal (#1532)

## Improvements

- **The MCP operation ledger persists off the invoking coroutine** (#1488), and `open_workspace`
  reports a window that never showed the Space (#976)
- **Plugin repository download-cache queries use an in-memory index** (#1495), and database policy
  calls that are constant per statement are evaluated once (#987)
- **CONTRIBUTING.md** added: fork CI setup, the validation gate and PR structure (#1116)
- **CI**: macOS and Windows legs run only for PRs into main (#1605, #1631), shared Gradle caches are
  seeded from dev (#1679), and pgTAP pre-pulls Supabase images from ECR Public (#1586)
- **IPC protocol 1.3.0** adds the additive `NodeSkipped` message

## Dependencies

- Bouncy Castle 1.86 and GraalVM Native Build Tools 1.1.13 (#1487)
