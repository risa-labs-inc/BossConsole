# BOSS v9.5.38

**Release Date:** 2026-10-05

Plugins can now update themselves: compatible releases install automatically once their views
are closed, with per-plugin opt-outs (#1812). The rare macOS startup crash that 9.5.37 still hit
is closed by loading the browser engine's toolkit before the JVM starts its own threads (#1815).

## Highlights

- **Automatic plugin updates** (#1812). A new Automatic Plugin Updates switch in Settings >
  Updates installs compatible plugin releases in the background. It is on by default in release
  builds, every plugin is included unless you opt it out, and an update waits until that
  plugin's tabs and panels are closed. Most plugins reload without restarting BOSS; the rest are
  staged for your next start, and a failed update restores the previous version
- **macOS startup crash fixed for good** (#1815). A small native agent now loads the browser
  engine's toolkit before the JVM starts any threads, so its memory allocator swap can no longer
  collide with a thread freeing memory. It only acts on what the previous launch verified, and
  falls back to the in-app preload on any doubt
- **Sharper favicons and native URL-bar shortcuts** (#1816). Tab rows and the home screen use
  higher-resolution site icons, and editing shortcuts in the native address field go to the URL
  editor
- **Laptop sleep no longer empties a window** (#1771). Waking a laptop that slept overnight
  keeps its tabs and Spaces in place

## Features

- **plugins**: automatic plugin updates with per-plugin opt-outs, failure fencing, serialized
  installers and a bounded retry budget per release (#1812)
- **mcp**: `pack_apply` prepares its install plan before approval and binds the approved
  downloads to their artifacts and provider registrations (#1714)
- **mcp**: a live workspace context bridge lets approved agents see open files and browser URLs
  across Spaces, behind the `workspace.context` permission and an approval prompt (#997)

## Bug Fixes

- **startup**: on macOS, the browser engine's native toolkit loads from a JVM agent before any
  JVM thread starts, closing the crash that remained after #1780 (#1815)
- **mcp**: dialog backgrounds stay opaque under Liquid Glass themes (#1827)
- **mcp**: tab inventories include tabs in a window with no Space assigned yet, and dynamic
  browser tabs (#1821)
- **mcp**: secret references are hardened against casing tricks, plaintext leaks and drift
  (#1784)
- **workspaces**: a window no longer empties after a long sleep (#1771)
- **workspaces**: nested left and top splits restore in their saved order (#1689); imports are
  gated on the reserved store files and go through unique naming (#1797, #1817); window-local
  Space saves get their review follow-ups (#1795); recovery write failures stay out of the
  layout watcher and a persistent one is logged once (#1746)
- **plugins**: the plugin tab descriptor package is shared with plugins (#1808)
- **plugin-store**: organisation members can download their organisation's plugins (#1596);
  direct version reads only see finalized rows (#1775), and over-cap JARs are refused on their
  declared size (#1783)
- **terminal**: closing stdin re-checks cancellation, and the input lock is released when its
  acquire is cancelled (#1777, #1779)
- **windows**: genuine UNC share paths keep their localhost authority (#1772), and the CLI
  installer's PATH update is bounded by a timeout (#1786)
- **single-instance**: the channel caps per-connection threads and keeps ownership under
  saturation (#1785)
- **auth**: the auth view model disposes cleanly and isolates its scope (#1802)
- **logging**: local settings and workspace decode failures are logged by type and path, never
  with file contents (#1788, #1793)
- **loader**: bytecode errors name the caller class, target owner and method candidates (#786)

## Improvements

- **browser**: higher-resolution, cached favicons reused across padding and theme variants, with
  site icon provenance preserved (#1816)
- **docs**: the README is redesigned around the launch film and product walkthrough, and
  showcases the BossConsole wiki (#1818, #1819)
