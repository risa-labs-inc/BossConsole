# BOSS v9.5.44

**Release Date:** 2026-10-13

A small maintenance release. The host now carries boss-plugin-api 1.0.99, which plugins using AI
Gateway prompt caching and the latest Fluck core need (#1881), and headless session import no longer
misreports an absent session file on Windows (#1869).

## Highlights

- **boss-plugin-api 1.0.99** (#1881). Adds AI prompt-cache extras, the finish reason and
  cache/reasoning usage reporting, so plugins built against it (AI Gateway prompt caching, Fluck
  core) load on this host
- **Session import on Windows** (#1869). An absent `BOSS_SESSION_IMPORT` file is detected before the
  POSIX ownership and mode checks run, so Windows no longer trips over checks it cannot answer
- **Reliable public release sync** (#1869). Releases are synced after a rerun of the release build,
  and a run that finds no fresh release skips publishing instead of failing

## Bug Fixes

- **auth**: detect an absent session import file before POSIX checks on Windows (#1869)
- **ci**: release sync matches the release by its publish time against the original run's creation
  time, which survives build retries, and skips cleanly when no release is found (#1869)

## Improvements

- **docs**: the README introduces always-on agents and business early access (#1868)

## Dependencies

- **plugins**: boss-plugin-api 1.0.97 -> 1.0.99 (#1881)
