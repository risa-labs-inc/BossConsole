# BOSS v9.5.42

**Release Date:** 2026-10-07

Editor saves no longer risk your only copy of a file: writes are staged and atomically replaced,
keeping permissions and file attributes (#427). This release also fixes a macOS startup freeze with
a maximized window, keeps tab favicons readable in light and dark themes (#1843), and makes plugin
update locking safer when several updaters run in one process (#1840).

## Highlights

- **Safer editor saves** (#427). A save now writes to a sibling file and replaces the original
  atomically, so a failed or interrupted write can no longer truncate the existing file. Permissions,
  ACLs and Windows hidden/archive flags are preserved
- **macOS no longer freezes on the splash screen** (#1843). A maximized main window could deadlock
  against AppKit at startup when it appeared under the pointer, leaving the app stuck at 0% CPU
- **Tab favicons stay readable in both themes** (#1843). Monochrome icons such as GitHub's no longer
  show black-on-dark; dark and light variants are cached separately and low-contrast ink is inverted
- **PDFs picked from New Tab open in the browser viewer** (#1839)

## Bug Fixes

- **editor**: writes stage a sibling file and promote it atomically instead of truncating the
  original first, and fatal write errors are reported rather than contained (#427)
- **editor**: saves keep POSIX permission bits, ACLs and DOS visibility flags; a denied ownership
  transfer on a shared writable file warns instead of blocking the save, and shared groups are kept
  (#427)
- **editor**: symlinks are saved through to their target, and a dangling link fails safely instead
  of being removed (#427)
- **window**: on macOS the main window's maximized bounds are set before it is shown, so showing it
  cannot deadlock the AppKit main thread (#1843)
- **tabs**: a sharper site icon that only matched the page favicon after inversion is recoloured to
  the page's own polarity, or the page icon is kept, so GitHub tabs no longer show a black octocat
  on dark themes (#1843)
- **tabs**: the favicon cache keeps a light and a dark variant per URL and reloads on a theme switch
  (#1843)
- **files**: PDFs selected through New Tab open in the browser's PDF viewer (#1839)
- **files**: a New Tab open deferred by a missing-plugin install now lands in the active pane
  instead of being dropped when its requested split has closed, and the picker's too-large warning
  shows the byte count again (#1839)
- **plugins**: plugin update leases are preserved during same-process contention, so a busy
  updater can no longer release another holder's OS file lock (#1840)
- **plugins**: concurrently created update lock directories are accepted, an uncertain channel close
  keeps its process fence, and the process registry no longer retains updater class loaders (#1840)

## Improvements

- **tabs**: tab chips and tab buttons invert monochrome favicons whose contrast against the tab
  background is below 2:1; coloured artwork is never altered (#1843)
- **plugins**: diagnostics explain when another installer holds a persistent update fence (#1840)
- **auth**: magic links support the Optimist chat web callback at `optimist.risalabs.ai`, with a
  test keeping the redirect allow-list and email templates in lockstep (#1829)
- **docs**: linked the plugin creation and publishing workflow (#1841)
