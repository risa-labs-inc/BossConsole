# BOSS v9.5.29

**Release Date:** 2026-09-27

A focused macOS fix: clearing the address field in the native title bar no longer navigates the
browser. The page now changes only when you press Enter (#1748).

## Highlights

- **Clearing the title bar address no longer navigates** (#1748). The native macOS address field
  is a search field, and AppKit sends its action when the field is cleared as well as when it is
  submitted, so emptying it could load a page you never asked for. Navigation now happens only
  when you press Enter in the field

## Bug Fixes

- **macOS**: the title bar address field submits only on Enter, never when its text is cleared
  (#1748)
- **macOS**: an Enter that arrives after the address field has been torn down is ignored rather
  than submitted (#1748)
