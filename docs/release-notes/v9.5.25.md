# BOSS v9.5.25

**Release Date:** 2026-09-25

The rest of the reviewed `dev` work reaches main in one release PR (#1684, 260 files). It adds
shareable Spaces, a persistent download history, `boss project-detect` and a Google OAuth redirect
for Fluck. It also puts external `boss://url` links behind a confirmation, verifies every Chromium
engine archive against the catalog checksum, and rebuilds project file discovery for search.

## Highlights

- **A saved Space can be shared across machines** (#1506). A materialised Space records absolute
  project paths in its tabs, working directories and commands. The new `workspace_make_portable`
  and `workspace_resolve_portable` MCP tools swap them for `{projectPath}` and bind a shared Space
  back to a local project, using the same substitution rules as templates. An import always mints
  a fresh id, so a shared Space cannot overwrite a local one
- **External `boss://url` links ask before they open** (#1482). A link another program asks BOSS
  to open is held and shown with its URL ("Open this link?") instead of opening a browser tab
  straight away. Opens are also rate-limited to five every five seconds
- **Chromium engine archives are installed only when their checksum verifies** (#1515). The GitHub
  backup source, and any candidate without a catalog sha256, used to be extracted without a
  check. Engines now follow the same rule as plugin updates: an archive that cannot be verified is
  refused, and the version picker lists only checksum-backed versions
- **Download history survives a restart** (#1477). Completed downloads are recorded in
  `~/.boss/download-history.json`, capped at the 500 newest. `downloads_history_list` and
  `downloads_history_clear` let an agent check what landed and where. The list can contain signed
  URLs, so it asks by default, like `secret_get`

## Features

### Spaces and CLI

- **`boss project-detect`** (#1517) reports a project's languages, tools and frameworks from its
  local files (`boss project-detect --path . --json`). The walk is bounded, including Cargo test
  detection by directory depth

### Backend

- **Fluck OAuth redirect as an edge function** (#1520). The `fluck-oauth` function replaces a
  callback served behind a Tailscale Funnel hostname on one machine. It verifies a signed,
  single-use, short-lived `state`, exchanges the code, and writes the refresh token into Secret
  Manager as the BOSS user named in that state. The signing key is bound to its user. The nonce
  check tolerates up to one minute of database clock skew without allowing replay. Spent nonces are
  kept for that extra minute as well, and malformed input is refused separately from a replay

## Bug Fixes

### MCP

- **The approval dialog's answer stays on screen at any window height** (#1683). A long
  description and argument list could push Allow and Deny below the window edge, so the prompt
  could only time out and deny. The card is now capped to the window, the header and action row
  are pinned, the body scrolls, and the description collapses behind Show more
- **Invoke arguments are validated against the tool's `inputSchema`** (#1493). Non-object
  arguments are refused instead of running with empty arguments, and validation is bounded and
  separate from the registry lifecycle
- **Plugin-pack messages no longer describe what did not happen** (#1678). A failed first install
  of a pinned release now says "Nothing was changed" instead of asking the user to restore a build
  that never existed. An empty pack is no longer reported alongside a type error in the same pack

### Plugins

- **Thin plugins load again on JDK 17** (#1684). Repeated reflective calls into a plugin class
  failed once the JVM generated an accessor. `jdk.internal.reflect` now resolves parent-first like
  the other platform packages, without reopening arbitrary host-library fallback
- **Single-instance, plugin, path and window lifecycle hardening** (#1489). The single-instance
  channel now checks who owns the socket, persisted plugin jar paths are confined, and plugin
  sandbox cleanup finishes after a timeout

### Auth and security

- **One passkey sign-in attempt at a time** (#1382). A superseded attempt could still fire a second
  login success or reopen the QR dialog with a stale cross-device session. A new attempt now
  cancels the old one, cancellation propagates through the auth chain, and dismissing the QR
  dialog clears the whole cross-device identity
- **Passkey script names cannot escape the script directory** (#1493). The Swift and PowerShell
  executors refuse any name containing separators or `..` before any filesystem work
- **Passkey edge-function logs mask emails, user ids and session ids** (#1490)
- **BOSS AI token eligibility is shared between `/auth/token` and `/auth/exchange`** (#1509)
- **Kernel IPC message text can no longer forge log records** (#1513). Unicode format characters
  are neutralized and escaped text stays unambiguous

### Tabs and UI

- **A tab drag cleans up after itself** (#692, #690). When pointer input restarts mid-drag, the
  drag ghost no longer stays stuck on screen. Cleanup belongs to the drag session that started it,
  so it cannot cancel a newer drag of the same tab
- **The workspace health dialog stays open in focus mode** (#1688). Opening it moved the pointer
  off the auto-hiding bottom bar, which hid the bar and closed the dialog with it. The Fix button is
  also hidden when there is no window to send the fix to

### Git and projects

- **The native Commit dialog stays bound to its own project** (#1484). Stage, unstage, commit and
  amend now use the project captured when the dialog opened, not the process-wide Git project.
  Sign-off goes through `git commit --signoff`, so it uses the repository's committer identity.
  Nested untracked files are listed too
- **Clone retry keeps what you entered** (#1476) after a failed clone
- **New project setup is kept when creation fails** (#1484)

### Search

- **Project discovery is shared by filename indexing and content search** (#1481). The walk
  follows nested `.gitignore` files, stays within the project across links, and is bounded. An
  unreadable child directory is skipped and reported as a partial result instead of discarding
  every result. Tab search reads UI state on the main thread and scores results off it

### Persistence and ids

- **Ids minted from a timestamp are unique** (#1478). Bookmarks, collections, tabs and sidebar Git
  tabs used `<prefix>-<epochMillis>`, so two created in the same millisecond during an import,
  restore or burst of agent calls collided. They now carry 16 hex digits of entropy
- **Recent pages keep their dismissals while startup loading is in progress** (#1477)
- **Workspace placeholders keep quoted templates and inert substitution intact** (#1526), including
  `&&` in Windows project paths

### Terminal and kernel

- **A non-positive terminal queue timeout is refused** (#1681)
- **Tuned JVM restarts merge heap flags additively and never shrink the heap** (#1528)

### Logging

- **Log capture is bounded** (#1492, #1684). Overflow drops the oldest entry atomically, and dispatcher
  shutdown can no longer race a new generation

## Improvements

- The Chromium version cache no longer stores a list with a platform entry that has no checksum
  (#1684)
- Symlink tests are skipped on Windows runners that lack symlink privilege (#1048)
