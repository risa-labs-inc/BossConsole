# BOSS v9.5.32

**Release Date:** 2026-09-29

The browser engine moves to JxBrowser 9.5.2 (#1761), and a large batch of fixes lands from `dev`:
corrupt settings files are recovered instead of breaking startup, local files are no longer
echoed into logs when they fail to decode, and the MCP audit record is more complete (#1728).
On macOS, the sidebar and native glass now follow BossTerm more closely (#1765).

## Highlights

- **JxBrowser 9.5.2** (#1761). The integrated browser runs on the newer engine release
- **Corrupt settings recover by themselves** (#1728). A damaged keymap, zoom or Space settings
  file is set aside and reset, and a notice shows where the preserved copy went, kept until you
  acknowledge it (#938, #1725)
- **Private data stays out of logs** (#1728). A local file that fails to decode is logged by type
  and position only, never with its contents, so layouts, `user_data.json` emails and ids, and
  passkey ids no longer reach the log (#1703, #1727, #1760, #1762)
- **Sidebar and glass polish on macOS** (#1765). Favorites wrap to the sidebar's width, the resize
  handle is easier to grab, and glass settings apply immediately

## Features

- **cli**: `boss mcp ledger secrets` reports which tools received a credential through a secret
  reference, and when; `--provider` now matches a plugin (#1733)
- **terminal**: backend for terminal session sharing - owner-scoped RPCs, a broadcast relay with
  ticket-only admission, and account-level terminal settings (#1731, #1734)
- **browser**: browser calls can wait for the page to go quiet before returning (#1063)

## Bug Fixes

- **sidebar**: favorites wrap to the available width instead of a fixed four per row (#1765)
- **sidebar**: the resize gesture follows BossTerm's baseline and has a wider hit target (#1765)
- **macOS**: native glass uses BossTerm's compact unified toolbar and lets the window frame shape
  the backdrop, and theme or style changes apply without reopening the window (#1765)
- **workspaces**: an earlier session's Space set no longer overrules the newer crash-recovery
  record; both are written together as one locked unit, and a failed write no longer stops the
  layout watcher (#1713)
- **spaces**: a named save resolves which window owns it at the moment you press it (#1749)
- **plugins**: on Windows, a Downloads folder the user moved (for example to `D:\Downloads`) is
  followed, and plugins may read and write inside it (#1728)
- **plugins**: registrations from a closing window are replayed correctly onto the surviving one
  (#1356)
- **editor**: a stale navigation target is no longer replayed into a newly opened editor (#1405)
- **mcp**: legacy provider DENY rules are preserved across the plugin provider-id change (#1682)
- **mcp**: escalated shell calls are marked in the ledger, and `format` only counts as a
  destructive command when it is one, not in `--format json` or `clang-format` (#1698)
- **mcp**: a very long argument no longer crashes the audit record of a call that already ran
  (#1712)
- **kernel**: a requested action is checked against the plugin's registered manifest before
  dispatch (#1716)
- **ipc**: created and renamed paths are built in the proxy the same way the host builds them
  (#1553)
- **chromium**: engine archive extraction is capped against zip bombs and rejects directory
  payloads (#1546)
- **crash**: a heartbeat/disconnect race in the Supabase realtime client is contained instead of
  crashing the app (#1740)
- **dashboard**: dismissed recent files stay dismissed through startup loads (#1751, #1764)
- **performance**: the plugin heap is clamped before it bounds the initial heap (#1696)
- **plugin-store**: name sort sorts by name with stable pages, schema failures answer with a real
  400 body, and plugin authors can no longer set their own verified badge or move a plugin into
  another organisation (#1702, #1705, #1715, #1744)
- **deep-link**: Windows's expected missing `APP_OPEN_URI` action is no longer logged as a warning
  (#1537)

## Improvements

- **build**: every module fails on skipped or never-run tests, in Gradle and in the IDE, and
  `buildSrc` pins JUnit so that guard is live (#1699, #1708, #1709)
- **settings**: any settings or state writer that falls back to a plain, non-atomic write fails a
  test (#1701, #1704)
- **auth**: passkey attempt and auth arguments are pinned by tests (#1691)

## Dependencies

- JxBrowser 9.5.0 to 9.5.2 (#1761)
- Kotlin 2.4.10 to 2.4.20 (#654)
- Compose Multiplatform 1.12.0 to 1.12.1 (#1757)
- Gradle wrapper 9.7.1 to 9.8.0 (#1759)
- `io.netty:netty-transport-native-unix-common` 4.2.17.Final to 4.2.18.Final (#1758)
